# Помощник Николая — самостоятельное приложение для Android

Версия 1.2. Создано для мастера по установке и обслуживанию водяных фильтров.

## Что уже работает

- Заявки: имя, телефон, адрес, дата выезда, время «не раньше», примечания, длительность, статус.
- Несколько фильтров в одном заказе: количество, цена продажи, закупочная стоимость. Работа и расходы на выезд — отдельно.
- Полученная оплата, частичная оплата, долг, переплата с подтверждением.
- История клиента по нормализованному телефону: 8XXXXXXXXXX и +7XXXXXXXXXX считаются одним номером.
- План на выбранный день и маршрут с перестановкой вверх/вниз; порядок сохраняется.
- При наличии координат — приближённый порядок по близости. Координаты вводятся вручную; платного геокодирования нет.
- Кнопка «Ехать» открывает Google Maps для конкретного адреса или координат. Звонок и WhatsApp открываются по нажатию; сообщения автоматически не отправляются.
- Аналитика за период по дате выполнения: выручка, количество заказов, уникальные клиенты, количество фильтров, записанные оплаты, задолженность, остаток после внесённых расходов, таблица по именам и телефонам.
- CSV с разделителем «;» и BOM для открытия в Excel. В итоговых колонках сумма заказа записана только в первой строке, чтобы не дублировать выручку при суммировании.
- Справочник фильтров с редактируемыми ценами, закупкой и сроком замены. Изменения справочника не пересчитывают старые заказы.
- Список приближающегося обслуживания по последней замене каждого вида фильтра у клиента.
- JSON-копия и восстановление с проверкой формата. Перед восстановлением скачивается копия текущих данных.
- Отдельный деморежим с вымышленными заявками; рабочие записи не меняются.
- Прямое распознавание речи при поддержке браузером; запасной способ — диктовка клавиатурой Android.
- Озвучивание завтрашних заявок и маршрута, кнопка остановки.
- PWA: установка на главный экран, локальное хранение, кэш приложения для работы без сети после первой успешной загрузки.

## Версия 1.2

Точка здания выбирается кнопкой «Найти по адресу» из результатов Nominatim/OpenStreetMap. Поиск только по действию пользователя, без автодополнения, с ограничением частоты и кэшем в текущей сессии. Сервису отправляется только адрес здания без имени, телефона, квартиры. Информация об условиях: https://operations.osmfoundation.org/policies/nominatim/ . Сервис ограничен умеренным использованием, не предназначен для массового поиска и может быть недоступен. Автоматической гарантии точности нет: мастер выбирает и проверяет здание. Для большого тиража следует выбрать собственный/лицензированный геокодер.

Резервные копии имеют имя `nikolai-work-…json`, `nikolai-test-…json` или `nikolai-demo-…json`. Добавлена отправка файла в системное меню сохранения телефона. Восстановление проверяет режим и сохраняет локальный снимок предыдущей базы; кнопка отмены возвращает этот снимок. Он не защищает от очистки браузера — внешние файлы копий всё равно нужны.

## Демо, тест и инструкция

- `/?mode=demo` — демонстрационные заявки, хранятся отдельно от рабочих.
- `/?mode=test` — отдельная учебная база; при первом открытии пустая.
- `/?mode=work` — рабочие данные. Имеющийся ключ `water-master-v1` сохранён.
- `/instruction.html` — инструкция для Николая и сценарий проверки.

Переименование не меняет домен и не переносит/не сбрасывает клиентские записи.

## Изменения версии 1.1

- «Составить маршрут» открывает ту же дату, что выбрана в рабочем дне. После сохранения заявки рабочий день и маршрут переходят на её дату.
- В маршруте появились переключатели дат с количеством незавершённых заявок и пояснение про заявки без координат.
- «Заполнить из текста» показывает распознанные поля внутри карточки, а при пустом поле объясняет, что нужно ввести текст. Поддержаны двоеточия, точка с запятой и простой формат «Алия, +7…, Абая 150, завтра».
- Уведомления об ошибках видны поверх открытой карточки.
- У звонков международный номер с плюсом; кнопка WhatsApp обозначена как чат. Добавлена карточка контакта с копированием номера и подсказкой для встроенного браузера.
- Поля на маленьком экране имеют размер шрифта 16px и одну колонку, чтобы уменьшить риск автоматического увеличения формы в iOS. Физический iPhone в среде разработки недоступен — фактическое открытие телефона и WhatsApp нужно проверить на устройстве.
- Версия структуры клиентских данных и ключи хранилища не менялись; рабочие записи не сбрасываются.

## Первые действия мастера

1. Открыть постоянную HTTPS-ссылку приложения в Chrome на Android.
2. Меню ⋮ → «Установить приложение» или «Добавить на главный экран».
3. В «Настройках» заполнить справочник своих фильтров, цены, закупку и интервалы замены.
4. Если нужен расчёт порядка по близости — указать координаты стартовой точки.
5. После звонка: «Новая заявка», заполнить карточку, сохранить.
6. Вечером: «Маршрут», выбрать завтра, упорядочить и проверить ограничения по времени.
7. После выезда: открыть заявку, выбрать выполненные позиции, записать работу и оплату, статус «Выполнен», дата выполнения, сохранить.
8. Смотреть отчёт в «Аналитике». Регулярно скачивать резервную копию.

## Голосовой ввод

Кнопка микрофона в приложении использует SpeechRecognition/Web Speech, если доступна. Реализация браузера может обращаться к внешнему сервису распознавания, требовать интернет и разрешение на микрофон. Приложение не использует платные API-ключи. Аудиозаписи самим приложением не сохраняются.

Надёжный запасной способ: нажать поле голосовой заметки и использовать микрофон клавиатуры Gboard. Затем нажать «Заполнить из текста».

Поддерживаемый шаблон:

> Имя Алия, телефон 87011234567, адрес Алматы Абая 150, завтра, после 14:00.

Результат работ можно продиктовать в открытой карточке:

> Работа 3000, получил 13000, расходы 1000, выполнено.

Фильтры и количество выбираются в форме. Произвольный разговор приложение не понимает как ИИ. Необработанный текст сохраняется в примечании; проверьте всё перед сохранением. Цифры лучше диктовать отчётливо; суммы словами не разбираются.

Озвучивание использует синтез речи устройства. В настройках Android должен быть доступен русский голос. Работа без интернета зависит от установленного речевого движка и голосового пакета. Фоновое прослушивание и автоматические утренние объявления не реализованы.

## Важные границы расчётов

**Маршрут.** Используется алгоритм ближайшего соседа по прямому расстоянию на сфере. Это не оптимизация по дорожной сети, пробкам и временны́м окнам. Без координат заявки идут в конец и переставляются вручную. Время «не раньше» показано мастеру, но автоматически не планируется. Длительность работ хранится как справочная информация; время прибытия не рассчитывается.

**Деньги.** Выручка — сумма фильтров и работы по выполненным заказам с датой выполнения в выбранном периоде. «Получено» — текущее суммарное значение оплаты этих же заказов. Это не отчёт о движении денег по датам платежей. Частичная оплата обновляется в карточке общим накопленным итогом. Предоплаты незавершённых заказов видны в карточках, но не в отчёте по выполненным заказам. Чистая бухгалтерская прибыль не рассчитывается: показанный остаток учитывает только внесённые закупки и расходы на выезд.

**Повторная замена.** Это ориентир для проверки мастером, не техническое предписание. Учитывается последняя замена данного вида фильтра у клиента; отдельные установки одного типа по разным адресам одного клиента пока не разделяются.

## Данные и безопасность

- Рабочие записи в localStorage под ключом `water-master-v1`, демо — `water-master-demo-v1`.
- Ключ деморежима в sessionStorage `water-demo`.
- Все клиенты и суммы хранятся в браузере одного устройства. На сервер приложения они не отправляются.
- Нет встроенной синхронизации, удалённого резервного копирования, аккаунтов мастеров и шифрования локальной базы. Защитите телефон блокировкой экрана.
- Карты и WhatsApp получают адрес/номер при нажатии соответствующих кнопок; речевой движок может передавать аудио своему провайдеру.
- Смена домена, браузера или телефона создаёт отдельное хранилище. Сначала скачайте JSON-копию, затем восстановите на новом устройстве/домене.
- Не очищайте данные браузера до создания копии. Файл копии содержит телефоны и адреса клиентов — храните его приватно.
- Несколько одновременно открытых вкладок с редактированием не поддерживаются: используйте одну.
- Telegram-бот не подключён: его исходники для этой работы не предоставлялись. Приложение может работать самостоятельно.

## Структура исходников

- `./index.html` — интерфейс и форма заявки.
- `./style.css` — внешний вид, адаптация под телефон.
- `./app.js` — экраны, события, хранение, голос, отчёты и резервные копии.
- `./core.js` — финансовые расчёты, проверка данных, маршрут, разбор шаблонных фраз и сроки обслуживания.
- `./sw.js` — кэш приложения без хранения клиентских записей.
- `./manifest.webmanifest`, иконки — установка на Android.
- `tests/core.test.js` — проверка важных расчётов и восстановления.
- `run-local.py`, `start-windows.bat` — локальный запуск при установленном Python.

Никаких npm-зависимостей, ключей ИИ и платных API нет. Можно редактировать в VS Code вручную или с любым доступным помощником. Подписки на внешних помощников для работы приложения не нужны. Доступность размещённой ссылки зависит от выбранного хостинга; исходники позволяют перенести приложение.

## Локальный запуск

Нужен Python 3. Из папки проекта:

```sh
python3 run-local.py
```

На Windows при наличии Python можно открыть `start-windows.bat`.

Открыть `http://localhost:8080`. Не запускать двойным нажатием на `index.html`: ES-модулям нужен HTTP-сервер. `localhost` подходит для разработки; для установки и микрофона на телефоне используйте HTTPS-размещение. Сервер по умолчанию доступен только на компьютере, на котором запущен.

Проверка расчётов при установленном Node.js:

```sh
node --test tests/core.test.js
```

## Размещение независимо от этого чата

Достаточно любого статического HTTPS-хостинга. Публиковать нужно **содержимое папки `dist`**, а не весь архив. Сборки нет; выходная папка — `dist`. Не загружайте файлы резервных копий с клиентами в репозиторий и на хостинг.

Вариант GitHub Pages:

1. Создать собственный репозиторий.
2. Загрузить файлы из `dist` в корень ветки `main` (не личные резервные копии!).
3. Settings → Pages → Deploy from a branch → `main` / root.
4. Использовать выданную GitHub HTTPS-ссылку; выбрать один постоянный адрес.

Доступность бесплатного размещения и условия зависят от тарифа/настроек хостинга. Подключение платного домена не требуется для работы приложения.

## Как обновлять без потери записей

1. В приложении скачать резервную копию.
2. Сохранить предыдущие исходники.
3. Внести изменения в VS Code. Сохранить существующий ключ `water-master-v1` и структуру данных.
4. Если меняется формат данных — написать миграцию старой версии, проверить на копии; не удалять старые данные при ошибке чтения.
5. Обновить имя кэша `CACHE` в `./sw.js`, если меняется оболочка приложения.
6. Запустить проверки расчётов; вручную проверить добавление, изменение, отчёт, копию и восстановление.
7. Загрузить новые файлы на **тот же адрес**. Обновить страницу при интернете; закрыть остальные вкладки, снова открыть приложение при необходимости.
8. Проверить, что заявки остались на месте. При смене адреса — восстановить JSON-копию.

Нельзя заменять ключ хранилища или очищать localStorage ради обновления интерфейса. Копия программы и копия клиентских данных — разные файлы; сохраняйте обе.

## Инструкция для следующего разработчика / ИИ

> Это самостоятельная PWA «Помощник Николая» на HTML/CSS/JavaScript, без фреймворков и внешних зависимостей. Сначала прочитай README и `./core.js`. Сохрани текущие ключи localStorage и пользовательские записи. Перед изменением структуры добавь миграцию, не сбрасывай базу. После изменения запусти `node --test tests/core.test.js`. Не добавляй сервер, API-ключи и платные сервисы без отдельного согласования. Не заменяй реальные данные демопримерами. Интерфейс должен оставаться удобным на Android от 360px. При изменении кэшируемой оболочки обновляй версию в `sw.js`.
